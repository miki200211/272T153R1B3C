## 🌟 系統亮點與核心特色

### 1. 📅 272梯 軍旅役期時光軸 (Military Timeline)
* **役期起迄**：`2026/08/12 入伍` ➔ `2026/08/21 家屬懇親日` ➔ `2026/12/13 光榮退伍`（總役期 124 天）。
* **動態儀表板**：即時計算已服役天數、退伍倒數剩餘天數與役期進度百分比（%），搭配軍規金綠迷彩流光進度條。
* **智慧狀態標籤**：歷史日程標記 `✅ 已達成`、當天日程脈衝高亮 `🔥 今日進行中`、未來日程精準標註 `⏳ 倒數 X 天`。
* **後台 Excel 同步**：支援直接在 Google 試算表 `Timeline` 分頁新增、修改日程並即時雙向同步！

### 2. 👥 建制班級名冊 (Squads 1 ~ 9)
* **滿編 98 位弟兄**：完整建置 1~9 班名冊，清晰顯示學號、姓名、綽號、公差職責與個人夢想。
* **軍便服雙照片**：支援上傳大兵軍裝照與私人便服照。
* **社群一鍵串連**：提供 IG 一鍵跳轉個人頁面、LINE 帳號快速複製功能。

### 3. 🪖 連隊長官與幹部專區 (Cadres)
* **嚴格軍階職等排序**：幹部卡片自動依階級順序排列（士官長 ➔ 上士 ➔ 中士 ➔ 下士 ➔ 一兵）。
* **雙面 3D 翻轉名片**：正面展示軍服英姿與職務，背面收錄軍旅座右銘、公務 LINE 與連絡資訊。
* **各班帶班幹部連動**：班級名冊頂部自動標註帶班班長與副班長資訊。

### 4. 🏢 兩寢一套房・現代化生活大樓寢室配置 (Rooms 1 ~ 11)
* **金六結南屏樓興安專案**：完整還原現代化新營舍「兩寢一套房」空間藍圖。
* **左右翼對稱佈局**：
  ```
  [ 左翼 5 床位 (含帶班幹部下鋪) ]  ⇋  [ 🚿 中央獨立套房衛浴 (超大洗手台/肥皂/淋浴/廁所) ]  ⇋  [ 右翼 5 床位 ]
  ```
* **跨平台智慧排版**：電腦大螢幕呈現沉浸式橫向三翼對稱藍圖，手機端自動切換為垂直順暢流式排版。

### 5. ⚡ 三連傳奇榜 (Legends Board)
* **弟兄爆笑回憶**：紀錄連隊經典事蹟、天兵爆笑瞬間與熱血回憶。
* **即時狂讚互動**：支援 `[ 👍 狂讚 (X) ]` 與取消讚，全連弟兄即時為傳奇灌票。
* **人氣排行榜**：依獲讚數自動降序排列，前三名頒發 `🥇 狂讚榜首`、`🥈 人氣亞軍`、`🥉 人氣季軍` 勳章，並於首頁頭條展示！

### 6. 📖 國軍莒光作文簿 (Diaries)
* **擬真軍規信紙**：綠色書眉、紅色界線邊條、真實稿紙格線排版。
* **長官官方評閱章**：卡片右下角蓋印「輔導長 / 連長 官方評閱紅章」。
* **心得點讚排行**：弟兄熱門推薦點讚 `[ ❤️ 點讚 (X) ]`，獲讚最高的心得同步於首頁「莒光熱門第一」精選推薦！

### 7. 📱 手機極致優化 (Mobile-First Experience)
* **極簡頂部導覽列**：左上角 `⭐️ 1B3C`、中間圓形旋轉同步鈕 `🔄`、右上角緊湊學號膠囊 `👤 #13005`。
* **底部快速選單**：首頁、幹部、班級、寢室、日記五大專區一鍵切換。
* **全域彈出選擇器**：快速選擇 9 個建制班級與 6 大套房寢室模組。

### 8. 🔒 身分驗證與安全管理 (Auth & Security)
* **預設學號登入**：學號（如 `13005`）與幹部帳號（如 `1B3C001`），密碼預設亦為學號。
* **首次登入強制作業**：首次登入自動跳出密碼修改視窗，確保個人隱私安全。
* **管理員一鍵重設**：若弟兄忘記密碼，可由管理員（`13055` 黃敬堯）於後台一鍵重設為預設學號。

## 🚀 部署與維護指引

### Google Apps Script 後端部署 (Web App)
1. 在 Google Drive 建立名為 `153R1B3C_Database` 的試算表。
2. 點選 **「擴充功能」 ➔ 「Apps Script」**。
3. 將本專案 [`gas/Code.gs`](file:///d:/code/Project/153R1B3C/gas/Code.gs) 內容貼入編輯器中。
4. 在頂部函式選擇 **`setupDatabase`** 點擊執行，系統會自動在試算表中建立好 `Members`, `Cadres`, `Timeline`, `Legends`, `Diaries` 5 張工作表！
5. 點選右上角 **「部署」 ➔ 「新增部署作業」 ➔ 選擇「網頁應用程式」**：
   * **執行身分**：`我 (您的帳號)`
   * **誰可以存取**：`所有人 (Anyone)`
6. 複製取得的 Web App 網址，貼入 [`js/config.js`](file:///d:/code/Project/153R1B3C/js/config.js) 的 `DEFAULT_GAS_API_URL` 即可！
